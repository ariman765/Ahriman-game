Проверка сети для кооператива

Игры используют сервер знакомства игроков (PeerJS) и STUN для WebRTC. Если «Создать комнату» пишет ошибку network без VPN, скорее всего провайдер блокирует эти адреса. Нажмите «Проверить» — страница опросит запасные серверы прямо из вашего браузера. Результаты никуда не отправляются.

Отчёт


    

    
Таймаут каждого теста — 6 секунд. Все проверки запускаются одновременно.
