# Net API — слой сети w40k-town

Файлы: `rtc-signal.js` (транспорт) и `net.js`. Подключайте их в этом порядке до `game.js`. Глобальный объект: `window.Net`.

Сеть как в кооперативе «Ариман»: один браузер — хост, остальные подключаются напрямую через WebRTC. Сервер PeerJS больше не нужен: `rtc-signal.js` (`window.RtcPeer`, интерфейс как у PeerJS) передаёт offer/answer параллельно через публичные MQTT-брокеры (hivemq, mosquitto, emqx; свой мини-клиент MQTT 3.1.1 поверх WebSocket) и Nostr-релеи (nos.lol, nostr.mom, relay.snort.social, relay.primal.net, offchain.pub; эфемерные события kind 25050, подпись BIP-340 своим кодом). Дубликаты отбрасываются по id сообщения. STUN по порядку: Cloudflare, Twilio, Sipnet, Google. Свой сервер не нужен. Хост авторитетен: проверяет скорость и телепорты, чистит имена и чат, рассылает события только игрокам на той же карте и отдаёт полный снимок позднему входящему.

Для тестов и разработки можно подставить `window.Peer` до загрузки (см. `tests/mockpeer.js`) — тогда используется он. Если `rtc-signal.js` не загрузился, `net.js` пробует подгрузить его сам, а в крайнем случае — PeerJS с CDN (старый путь через 0.peerjs.com).

Параметры адреса (для отладки): `?stun=stun:host:port,…` — свои STUN; `?turn=turn:host:3478&turnuser=…&turnpass=…` — добавить TURN; `?signal=mqtt` или `?signal=nostr` — только один вид сигнальных серверов; `?relays=mqtt:wss://…,nostr:wss://…` — свой список; `?rtcdebug=1` — лог в консоль.

## Старт

Зарегистрируйте обработчики `Net.on(...)` до вызова `host` / `join` / `offline`.

| Метод | Возвращает | Описание |
|---|---|---|
| `Net.host(name)` | `Promise<string>` | Создаёт комнату. Промис резолвится пятибуквенным кодом (как в кооперативе: без I, O, 0, 1). Пишет событие `hosted`. |
| `Net.join(code, name)` | `Promise<void>` | Входит в комнату по коду. Резолвится после снимка `welcome`. Пишет `connected`. |
| `Net.offline(name)` | `Promise<void>` | Одиночный режим без сети: как хост без пиров. Клиент может на нём разрабатывать карты и UI. Пишет `hosted` с `{code:null, offline:true}`. |
| `Net.leave()` | — | Выйти. Если это хост, остальные получают `disconnected`. |
| `Net.inviteLink()` | `string` | Ссылка вида `…?room=CODE`. В офлайне — пустая строка. |
| `Net.roomFromUrl()` | `string` | Читает `?room=CODE` из адреса страницы (заглавными). |

## Действия

| Метод | Описание |
|---|---|
| `Net.move(x, y, dir, anim)` | Позиция. Отправка с клиента ограничена ~15 Гц. Предсказание на клиенте — задача клиента: `me()` обновляется сразу, хост может подрезать скорость. |
| `Net.chat(text)` | Сообщение: обрезка пробелов, максимум 200 символов, простой лимит частоты (~400 мс). Возвращает `false`, если пусто или слишком часто. |
| `Net.emote(id)` | Эмоция (`string` или `number`). Рассылается по текущей карте. |
| `Net.sit(bool)` | Сесть / встать. |
| `Net.setLook(look)` | Любой JSON-образ персонажа, лимит ~4 КБ. Слишком большой — событие `error` с кодом `look-too-big`, метод возвращает `false`. На хосте, если загружен `window.FACTIONS`, образ прогоняется через `FACTIONS.migrate` и при невалидной паре side/faction подставляется значение по умолчанию из `migrate({})`. |
| `Net.goMap(mapId)` | Сменить карту. Сигнатура без изменений. Если мир не зарегистрирован — как раньше: клиент сразу меняет `me().map`, хост подтверждает снимком. Если мир задан через `setWorld`, хост пускает переход только с площадки и ставит игрока на спавн цели (см. ниже). |

| `Net.typing(bool)` | Индикатор «печатает…». Клиент шлёт не чаще ~1 раза в секунду (повтор `true` раньше — пустая операция, возвращает `false`), `false` уходит сразу. Хост хранит флаг у игрока, рассылает его в `players` (поле `typing`) и событием `typing`, гасит его через ~6 с без повторного `typing(true)` и при отправке чата этим игроком. На `blur` окна `net.js` сам шлёт `false`. Подробнее — `HOOKS_KANAYA.md`. |
| `Net.setWorld(world)` | Регистрирует описание мира для проверки телепортов и (необязательно) лимит скорости. Хост использует **свою** копию. Без вызова поведение сети прежнее. |

Имена и чат **не экранируются** (HTML — на стороне отрисовки). Управляющие символы (диапазон C0/C1) вырезаются. Пустое имя заменяется на `Гость-NNN`. Максимум имени — 24 символа.

## Мир, площадки и телепорт — `Net.setWorld(world)`

Клиент **обязан** вызвать это на хосте (и лучше на каждом клиенте тоже) после загрузки карт, до того как игроки пользуются площадками. Офлайн-режим — тоже «хост».

```javascript
Net.setWorld({
  maxSpeed: 400,          // необязательно, по умолчанию 400 px/с; можно вызвать отдельно
  maps: {
    hub: {
      spawn: { x: 328, y: 296 },          // пиксели мира
      pads:  [{ x: 80, y: 224, r: 24 }]   // r по умолчанию 24; хост добавляет допуск ~24 px на задержку сети
    },
    cantina: { spawn: { x: 208, y: 234 }, pads: [{ x: 208, y: 234 }] }
  }
});
```

Когда `maps` задан (непустой объект):

- `goMap(mapId)` принимается, только если целевая карта есть в `world.maps` **и** игрок сейчас стоит у площадки текущей карты: расстояние ≤ `r` (или 24) + 24 px допуска.
- Хост сам ставит игрока на `spawn` целевой карты (если спавна нет — на первую площадку) и подтверждает снимком. В снимке есть поле `you` (карта, x, y, look…) — `net.js` применяет его к `me()`.
- Отвергнутый переход: событие `error` с кодом `teleport-denied` и русским текстом («…встань на площадку» или «…такой локации нет»). У клиента `me().map` (и позиция) **откатываются**.
- Повторный `goMap` на ту же карту — пустая операция.

Поля можно обновлять по отдельности: `setWorld({ maxSpeed: 500 })` не сбрасывает карты, `setWorld({ maps: {…} })` не сбрасывает скорость. `setWorld(null)` или пустые `maps` снова выключают проверку площадок.

## Фракции

Если на странице есть `window.FACTIONS` с методами `migrate(look)` и `valid(side, faction)` (их даёт `factions.js`), хост вызывает их, когда образ приходит при входе, `setLook` или из сохранённого списка друзей. Старые поля вроде `arch: 'tsons'` / `legion: 'ts'` / `wolf` должна превратить `migrate`. Если после миграции `valid` возвращает false, хост берёт `side` и `faction` из `FACTIONS.migrate({})`. Лимит образа по-прежнему ~4 КБ. Без `FACTIONS` образ проходит как есть.

## События — `Net.on(evt, cb)` / `Net.off(evt, cb)`

`on` возвращает функцию отписки.

| Событие | Полезная нагрузка | Когда |
|---|---|---|
| `hosted` | `{code, offline}` | Комната создана или включён офлайн. |
| `connected` | `{code, id}` | Клиент успешно вошёл и получил снимок. |
| `disconnected` | `{code, message}` | Хост ушёл или соединение с ним оборвалось. `message` — читаемый русский текст, например «Хост покинул игру. Сессия завершена.» |
| `error` | `{code, message}` | Ошибка брокера, WebRTC, не найденная комната, переполнение, слишком большой look и т.п. Не зависает молча. `message` на русском. |
| `players` | `{full:boolean, list:Player[]}` | Игроки **на моей текущей карте, без меня**. `full:true` — заменить список; `full:false` — патч полей (всегда есть `id`). Надёжнее опираться на `Net.players()`. |
| `chat` | `{id, name, text, t}` | Сообщение на моей карте. `t` — время хоста в мс. |
| `emote` | `{id, emote}` | Эмоция на моей карте. |
| `joined` | `{id, name}` | Кто-то вошёл в **комнату** (не смена карты). |
| `left` | `{id, name}` | Кто-то вышел из комнаты. |
| `status` | `{text, phase, open, total}` | Ход подключения на русском: «Подключаюсь к сигнальным серверам… 3/8», «Ищу комнату…», «Комната найдена, устанавливаю прямое соединение…». Если на `status` никто не подписан, `net.js` пишет текст в `#mStatus` (только до входа в игру). |

| `typing` | `{id, typing}` | Игрок на моей карте начал или перестал печатать (о себе не приходит). То же поле есть в `Net.players()`. |
| `event` | `{id, map, kind, startedAt, endsAt, seed, data, late?}` | Хост запустил мировое событие (на **любой** карте). Поздний вход: для каждого активного события после `connected`, с `late:true`. Время — часы хоста (`Net.hostTime()`). |
| `eventend` | `{id, map, kind}` | Хост досрочно завершил событие (`stopEvent`). Истёкшие по времени события просто пропадают из `Net.events()`. |
| `worldstate` | `{key, value, full:false}` или `{key:null, full:true, state}` | Хост поменял ключ общего состояния мира (`value:null` — ключ удалён). `full:true` — снимок всего состояния при входе. |
| `home` | `{owner, name, home}` | Я вошёл в келью `home:<owner>` (свою или чужую) — пришла расстановка хозяина (`home` — JSON-строка или `null`). Повторяется, пока я там, при каждой правке хозяина. |
| `homeinvite` | `{owner, name, room}` | Меня пригласили в келью (`room` = `'home:<owner>'`, можно сразу `goMap(room)`). |
| `homes` | `{list:[{owner, name}]}` | Изменился список открытых для всех келий (без моей). Первый раз — при входе в комнату. |

Коды `error` / `disconnected`: `lib`, `broker`, `timeout`, `not-found`, `bad-code`, `full`, `network`, `look-too-big`, `teleport-denied`, `spell-denied`, `spell-cooldown`, `home-too-big`, `home-closed`, `host-left`.

## Мировые события (хост решает)

| Метод | Описание |
|---|---|
| `Net.startEvent({map, kind, duration, seed?, data?})` | **Только хост.** `kind` — `[a-z0-9_-]`, до 32; `duration` в мс (3 с — 10 мин) или `endsAt` (часы хоста); `data` — любой JSON до 512 байт. Рассылает событие **всем** игрокам комнаты (не только на карте, чтобы при телепорте оно уже было известно). Возвращает событие или `null` (клиент, плохие данные, уже 16 активных). |
| `Net.stopEvent(id)` | **Только хост.** Завершить досрочно. У всех: `eventend`. |
| `Net.events(mapId?)` | Активные события (`endsAt > hostTime()`), по возрастанию `startedAt`, копии. С `mapId` — только для этой карты. |

Клиент не может создать событие: `startEvent`/`stopEvent` на клиенте возвращают `null`/`false`, а сообщения `event`/`eventEnd`/`world`, присланные клиентом хосту, хост игнорирует. Клиенты принимают их только от соединения с хостом.

Планировщик и отрисовка — в `events.js` (не в `net.js`): хост раз в 4–6 мин запускает событие на случайной занятой карте, длительность 45–90 с. Параметры адреса: `?eventEvery=секунды` (фиксированный интервал), `?eventLen=секунды`, `?events=0` (выключить авто-события). `window.WarpEvents`: `trigger(kind?, map?, секунды?)` (хост), `setEnabled(bool)`, `kindsFor(map)`, `info(kind)` → `{name, text}`, `active()`, `nextAt()`.

## Общее состояние мира (worldstate)

Ключ–значение, которое задаёт хост и видят все: погода по картам, время суток и т.п.

| Метод | Описание |
|---|---|
| `Net.setWorldState(key, value)` | **Только хост.** `key` до 64 символов, `value` — JSON до 2 КБ, до 64 ключей. `null`/`undefined` — удалить. Возвращает `true`/`false`. У всех (и у хоста) — событие `worldstate`. |
| `Net.worldState(key?)` | Без аргумента — копия всего состояния, с ключом — значение или `undefined`. |

Поздний игрок получает всё состояние в `welcome` (`worldstate` с `full:true`). Соглашение об именах (предложение): `time` → `'day'|'dusk'|'night'`, `weather:<mapId>` → `{kind:'snow'|'ash'|'rain'|'storm', power:0..1}`.

```javascript
// хост: ночь во всём мире и снег на Фенрисе
Net.setWorldState('time', 'night');
Net.setWorldState('weather:fenris', { kind: 'snow', power: 0.8 });
// любой клиент
Net.on('worldstate', w => { if (w.full) applyAll(w.state); else apply(w.key, w.value); });
```

## Заклинания

Заклинания идут как эмоции с id `'spell:<id>'` (см. `lore.js`). Если на странице есть `window.LORE`, хост проверяет каждое: `LORE.parseEmo(id)` (неизвестное — отбросить) и `LORE.canCast(spellId, look)` по образу **на хосте**. Недоступное заклинание не рассылается, а заклинатель получает `error` с кодом `spell-denied` («Это заклинание недоступно твоей фракции.»). Без `LORE` — проходят как обычные эмоции.

**Лимит частоты (батч 2).** Хост пропускает одно и то же заклинание игрока не чаще, чем раз в `LORE.SPELLS[id].cd` секунд (без `LORE` или без `cd` — 6 с; для задержки сети принимается повтор после 80 % перезарядки), и любые два заклинания одного игрока — не чаще раза в 0,4 с. Лишний каст не рассылается, заклинателю приходит `error` с кодом `spell-cooldown` («Чары ещё не перезарядились.»). Отклонённые (`spell-denied`) касты перезарядку не запускают. Обычные эмоции не ограничены. Свои касты хоста проходят через тот же лимит.

## Кельи игроков (батч 2)

Каждому игроку — своя келья: комната `'home:<id игрока>'`. Шаблон для спавна и площадки — карта `home` из `setWorld` (одна на всех). `goMap('home')` = своя келья. Для совместимости `Net.me().map` и `Net.myMap()` в своей келье по-прежнему возвращают `'home'`; точный id комнаты — `Net.myRoom()` (`'home:<мой id>'`). В чужой келье `me().map` = `'home:<id хозяина>'` (в `MAPS` такого id нет, `game.js` показывает карту `home`). У других игроков в `players()` поле `map` — всегда точный id комнаты.

| Метод | Описание |
|---|---|
| `Net.myRoom()` | Точный id моей комнаты (в своей келье — `'home:<мой id>'`, иначе как `myMap()`). |
| `Net.homeRoom(id?)` | `'home:<id>'`, без аргумента — своя. |
| `Net.homeOwner()` | id хозяина кельи, в которой я сейчас, иначе `null`. |
| `Net.setHome(json)` | Своя расстановка (строка или объект, JSON ≤ 2 КБ; на хосте проходит через `Home.validate`, если он есть). `null` — очистить. Видна всем как `p.home` в `players()`, гостям — событием `home`. Неверная/большая → `false` + `error` `home-too-big`. Подходит для `Home.onChange(json => Net.setHome(json))`. |
| `Net.home()` | Моя расстановка (как отправлена) или `null`. |
| `Net.homeOf(id)` | Расстановка игрока: из `players()` моей карты, из последнего события `home` или своя. |
| `Net.setHomeAccess(mode)` | Кто может войти: `'invite'` (по умолчанию: я и приглашённые), `'open'` (все), `'private'` (только я). Гости, которым больше нельзя, отправляются в хаб (Руины Просперо) с `error` `home-closed`. |
| `Net.homeAccess()` | Текущий режим. |
| `Net.openHomes()` | Кельи, открытые для всех (`'open'`), кроме моей: `[{owner, name}]`. Хост рассылает список всей комнате при каждом изменении и в `welcome`; хозяин ушёл — келья пропадает из списка. |
| `Net.homeInfo(id)` | Что известно о келье до входа (`id` или `'home:<id>'`): `{owner, name, home, open, invited}` или `null`. Имя берётся из игроков на моей карте, из приглашения, из списка открытых келий или из прошлого визита, так что его можно показать сразу при телепорте. |
| `Net.homeInvite(id)` / `Net.homeUninvite(id)` | Пригласить игрока (он получит `homeinvite`) / отозвать (если он в гостях — выселяется). |

- Пока `setHome` не вызывали, `net.js` сам берёт расстановку из `localStorage['w40ktown_home_v1']` (её пишет `game.js`) при старте и при входе в свою келью, так что визиты работают и без правок `game.js`.
- Войти в чужую келью: стоять на площадке, `goMap('home:<id>')`. Хозяина нет в игре / не пустил → `teleport-denied` («Келья недоступна: её хозяина нет в игре.», «Келья закрыта: хозяин тебя не пригласил.»). Хост подчиняется тем же правилам.
- Хозяин вышел из игры → его гости уходят в хаб с `home-closed`.
- При входе в `home:<id>` хост шлёт `homeInfo` (имя и расстановка хозяина) **до** снимка `players`, поэтому событие `home` приходит раньше, чем список игроков кельи.
- Чат, эмоции, «печатает» и события в келье видят только те, кто в ней. Мировые события (`events.js`) в кельях не запускаются.
- Для визита `game.js` делает `Net.on('home', h => h.owner === Net.me().id ? Home.leaveVisit() : Home.visit(h.home, h.name))`.

## Игрок

```
{id, name, look, map, x, y, dir, anim, sit, emote, typing, home}
```

- `Net.me()` — мой игрок или `null` до старта.
- `Net.players()` — остальные на моей карте (снимок, не включает меня).
- Карта по умолчанию: `"hub"`.
- Стартовая позиция: `(0, 0)` — клиент сам поставит персонажа через `move`.

## Память образа

Каждый клиент сам заводит устойчивый id в `localStorage` (`w40ktown_pid`). Хост помнит последние `name` и `look` по этому id (`w40ktown_roster`). Вернувшийся друг получает свой прежний образ из снимка `welcome`, даже если локально look подменили. Свои имя и образ хост тоже пишет в `localStorage` (`w40ktown_me`) и поднимает при `host()` / `offline()`.

## Ограничения хоста

- До 16 игроков вместе с хостом. 17-й получает `error` с кодом `full`.
- Скорость ограничена `maxSpeed` из `setWorld` (по умолчанию 400 px/с). Слишком далёкий скачок обрезается. Если мир не задан, после смены карты лимит сбрасывается, чтобы клиент мог сам встать на спавн. Если мир задан, спавн ставит хост, и большой скачок после телепорта уже не принимается.
- Чат и эмоции видны только на той же карте. `joined` / `left` — на всю комнату.
- Уход хоста: всем уходит `disconnected` с русским сообщением. Обрыв WebRTC обрабатывается так же.
- Ни один сигнальный сервер не ответил (~12 с), комната не найдена (~10 с), WebRTC не соединился или общий таймаут входа 25 с — `error` с русским текстом, промис `host`/`join` отклоняется.

## Дополнительно (не из контракта, но удобно)

- `Net.code` — текущий код комнаты (или `''`).
- `Net.isHost()` — хост или офлайн.
- `Net.isOffline()`
- `Net.isConnected()`
- `?peerhost=&peerport=&peerpath=&peersecure=1` действуют только в запасном режиме PeerJS.

## Код персонажа — `charcode.js`

См. `CHARCODE.md`: `CharCode.encode(look, name)` → `'AHR1-…'`, `CharCode.decode(code)` → `{look, name}`.

## Сенсорное управление — `touch.js`

На телефонах (или `?touch=1`; `?touch=0` — выключить) появляются джойстик и кнопки. Они шлют те же `KeyboardEvent` (`e.code`), что и клавиатура, тап по карте — `mousedown` на `#cv`. `window.TouchUI.tap('KeyX')`.

Черновой стенд: `demo.html` (не `index.html`) — цветные квадраты, WASD, чат, хост/вход/офлайн.

Клиенту (`index.html`, `game.js`) этот слой не правит.
